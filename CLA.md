## How to sign

When you open your first pull request in a repository of the organization, a check asks you to sign.
Read this agreement, then post this exact comment on the pull request:

> I have read the Ruchoir CLA and I hereby sign it.

The check records your GitHub account, the date and the pull request, and turns green. You do not
sign again for later pull requests, in any repository of the organization, unless the version of
this agreement changes.
